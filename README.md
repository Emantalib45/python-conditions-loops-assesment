# Python Programming Assignments

## Overview
This repository contains two beginner-friendly Python applications developed using basic Python programming concepts. These projects demonstrate the use of conditional statements, loops, input validation, counters, and accumulators.

---

## Task 1: Student Scholarship Eligibility System

### Topic
Conditional Statements (`if`, `elif`, `else`)

### Description
The Student Scholarship Eligibility System is a Python application that checks whether a student qualifies for a university scholarship based on academic marks, attendance percentage, and monthly family income.

### Eligibility Criteria
- Academic Marks must be at least 80%.
- Attendance must be at least 85%.
- Monthly Family Income must be Rs. 50,000 or less.

### Scholarship Categories
- **Full Scholarship:** Marks of 90% or above.
- **Partial Scholarship:** Marks between 80% and 89%.
- **Not Eligible:** If any eligibility condition is not satisfied.

### Features
- Collects student information.
- Validates marks, attendance, and income.
- Checks scholarship eligibility.
- Displays reasons for ineligibility.
- Generates a complete scholarship evaluation report.

### Python Concepts Used
- `input()`
- `float()`
- `if`, `elif`, `else`
- Logical operators (`and`, `or`)

## Task 2: Smart Pharmacy Inventory & Sales Management System

### Topic
Loop Structures (`for` loop, `range()`, Conditions, Counters, and Accumulators)

### Description
The Smart Pharmacy Inventory & Sales Management System is a Python application designed to manage medicine sales, check available stock, calculate daily revenue, and identify medicines that require restocking.

### Features
- Asks how many medicines need to be processed.
- Collects medicine name, available stock, unit price, and quantity sold.
- Checks medicine stock availability.
- Calculates sales amount for each medicine.
- Calculates remaining stock after each successful sale.
- Displays a low-stock warning when remaining stock is below 10 units.
- Calculates total pharmacy revenue.
- Counts medicines requiring restocking.
- Generates a final pharmacy report.

### Python Concepts Used
- `for` loop
- `range()`
- `if`, `else`
- Logical operators
- Counter
- Accumulator
- Arithmetic operations

## Requirements

- Python 3.x
- Any Python IDE or code editor (VS Code, PyCharm, IDLE, etc.)

## How to Run the Programs

1. Install Python on your computer.
2. Open your preferred Python editor.
3. Copy the respective Python code into a new file.
4. Save the files using the following names:

   - `Task1_Scholarship.py`
   - `Task2_Pharmacy_Management.py`

5. Run the programs using Python.

### Run Using Terminal

```bash
python Task1_Scholarship.py
```

```bash
python Task2_Pharmacy_Management.py
```
